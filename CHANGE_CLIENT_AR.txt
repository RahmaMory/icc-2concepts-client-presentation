تغيير النسخة لعميل جديد — أسرع طريقة
====================================

1) انسخي مجلد المشروع كاملًا وغيّري اسمه باسم العميل.
2) افتحي الملف الوحيد:
   src/data/client.ts
3) غيري اسم العميل والمجال والنص واللون والسعر والمدة.
4) ضعي رابط Gamma/PDF في proposal.url.
5) ضعي رابط Vercel الجاهز الذي أرسله المصمم في mainDemo.url.
6) ضعي روابط المواقع المشابهة في related[].url.
7) استبدلي الصور داخل public/assets/projects/ مع الحفاظ على المسارات أو عدليها في client.ts.
8) شغلي: npm install ثم npm run dev.
9) ارفعي نسخة العميل كمشروع Vercel منفصل.

المسارات الداخلية بدون Reload:
/                  الصفحة الرئيسية
/related           المواقع المشابهة
/view/proposal      العرض
/view/demo          موقع العميل
/view/project/:id   معاينة مشروع مشابه
